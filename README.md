# Happy in the Head — Premium Website Refresh

Static HTML/CSS/JS refresh preserving the original creative brand direction while improving:
- Responsive desktop/tablet/mobile UX
- Functional call, WhatsApp, Instagram and Google Maps CTAs
- WhatsApp appointment form
- Portfolio filters + accessible image lightbox
- Stronger Why Happy in the Head section
- Honest review section that links to live Google feedback rather than inventing testimonials
- Local SEO metadata + BeautySalon structured data
- sitemap.xml + robots.txt
- Optimized supplied salon/work images
- Reduced dependencies and no external image stock

## Files
- index.html
- styles.css
- script.js
- favicon.svg
- robots.txt
- sitemap.xml
- assets/

## Deployment
Upload the folder contents to Netlify, GitHub Pages, Vercel, or any static hosting provider.

## Important
The canonical/sitemap domain is set to `https://happy-inthehead.netlify.app/`. If the final deployment uses a different domain, replace that domain in `index.html`, `robots.txt`, and `sitemap.xml`.
